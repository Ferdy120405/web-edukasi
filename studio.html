Studio Animasi

Pratinjau animasi original dan rekam menjadi file video.

Pilih animasi, lalu tekan tombol rekam. Perekaman berjalan sesuai durasi animasi.

📌 Catatan perekaman

  • Gunakan Chrome atau Edge versi terbaru. Hasilnya berupa .mp4; jika browser belum mendukung, hasilnya .webm.
  • Jangan pindah tab atau meminimalkan jendela selama merekam, karena gambar akan tersendat.
  • Musik latar dan subtitle ikut terekam. Suara narator otomatis (text-to-speech) tidak ikut terekam karena dibuat oleh sistem operasi.
  • Agar narasi ikut terekam, rekam suara Anda sendiri untuk setiap adegan (mp3), simpan di folder audio/, lalu tambahkan audio: "audio/siklus-air/1.mp3" pada adegan yang sesuai di file animasi.
